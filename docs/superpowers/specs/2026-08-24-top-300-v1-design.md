# TOP-300 v1 Complete Product Design

## Purpose

TOP-300 is a reproducible breakout-trend forecasting system. It estimates which topics are most likely to enter the top 1–5% of attention in the next 24 hours, 72 hours, and 7 days while demand is still outrunning content supply.

## Principles

- no future leakage
- raw percentage growth is never sufficient by itself
- demand and supply are modeled separately
- probabilities must be evaluated with Brier score and top-K precision
- a transparent heuristic baseline remains available
- local sample data requires no API key
- outputs carry an explicit `as_of` cutoff

## Architecture

```text
Source adapters → Observation → immutable SQLite store → cutoff replay → feature extraction → heuristic/learned horizon models → calibration → opportunity ranking → CLI/backtest
```

SQLite is the v1 reference store for standard-library reproducibility. The storage interface remains replaceable with DuckDB/Parquet later.

## Required CLI

`init`, `ingest`, `features`, `train`, `forecast`, `rank`, `backtest`, `demo`.

## Lifecycle

`EMERGING → IGNITION → BREAKOUT → MAINSTREAM → SATURATED → DECLINING`

## Completion

A fresh environment can initialize, ingest, replay, compute features, forecast, train, rank, backtest, export and test without API keys.
