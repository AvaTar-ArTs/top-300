# TOP-300 v1 Implementation Plan

**Goal:** Deliver a runnable end-to-end trend forecasting product from local historical signals through ranked forecasts and walk-forward evaluation.

**Spec:** `docs/superpowers/specs/2026-08-24-top-300-v1-design.md`

## Tasks

1. Repair scaffold CI and preserve baseline contracts.
2. Add immutable observation model/store and cutoff replay.
3. Add CSV/JSON ingestion.
4. Build cutoff-aware feature extraction and leakage tests.
5. Add lifecycle and ranking.
6. Add heuristic and learned horizon forecasting, persistence and calibration.
7. Add walk-forward evaluation with Brier and precision@K.
8. Add CLI commands and a no-key end-to-end demo.
9. Record conversation evolution, audit, release packaging and verification.

## Global constraints

- explicit `as_of` cutoff everywhere
- no future data in features or model fitting
- zero-baseline growth never becomes infinity
- duplicate observations are idempotent
- learned models fall back to heuristic probabilities when class diversity is insufficient
- CI runs Ruff and pytest on Python 3.11
